# Добро пожаловать!
ЭПОС.Дельта — независимый некоммерческий проект, создаваемый энтузиастами и посвящённый разработке модификаций и дополнительных инструментов для [Электронной Пермской Образовательной Системы](https://epos.permkrai.ru/)
